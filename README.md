# auto-scheduler

## 💰 仕入れリサーチ（スーパーデリバリー → Amazon 自己発送）

スーパーデリバリーの商品ページを自動で1件ずつ開いて、単品価格・まとめ買い価格・JAN を集めます。
集めた JAN を Keepa で Amazon.co.jp と照らし合わせ、2個・3個セットを自己発送で売ったときの利益を計算して、利益率の高い商品を一覧にします。

ログインは自分でブラウザーに入力します。パスワードはこのプログラムには渡りません。

### 準備（最初の1回だけ・Windows）

1. このフォルダーを PC に置く（GitHub の「Code → Download ZIP」で落として展開）
2. `1_setup.bat` をダブルクリック
3. メモ帳が開いたら、`KEEPA_API_KEY=` の後ろに Keepa の API キーを、`SHIPPING_COST=` に送料（1回分・円）を書いて保存

### 使い方

| ファイル | やること |
|---|---|
| `2_sample.bat` | 見本として2件だけ保存し、価格や JAN がページのどこにあるかを `data\diagnose.txt` に書き出す |
| `3_collect.bat` | 企業の商品一覧 URL を貼る → ブラウザーでログイン → Enter。あとは自動で全商品を保存して `data\sd_products.csv` にまとめる |
| `4_keepa.bat` | JAN で Amazon の価格・ランキング・手数料率を調べて `data\amazon.csv` に保存 |
| `5_app.bat` | 画面が開くので、左のメニューの「仕入れリサーチ」で利益の出る商品を見る（セット数・送料・利益率はここで変えられる） |

- ページを開く間隔は 3〜5 秒です（サイトに負担をかけないため）。途中で止めても、次回は続きから再開します。
- 価格の読み取りルールは、実際のページを見る前の仮のものです。`data\diagnose.txt` を見て調整します。

### ⚠️ 注意

- `data\` フォルダー（卸価格・ログイン情報）と `.env`（API キー）は、GitHub に上げないでください。このリポジトリは公開されています。どちらも `.gitignore` で除外してあります。
- 卸価格は会員限定の情報です。「仕入れリサーチ」画面は自分の PC だけで使い、Streamlit Cloud などで公開しないでください。
